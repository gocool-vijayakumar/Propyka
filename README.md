# Propyka

Propyka is a PropTech application combining three areas:

1. Real Estate
   - Property listings
   - Buying
   - Renting

2. Marketplace
   - Construction materials
   - Civil-related products and services

3. Contractor & Customer Platform
   - Contractor profiles
   - Customer requirements
   - Connecting customers with contractors

The goal is to keep the initial architecture simple, clean and maintainable while allowing the application to scale in the future.

---

## Technology Stack

### Backend

- ASP.NET Core Web API
- .NET 8
- ASP.NET Core Identity
- Entity Framework Core
- PostgreSQL
- Npgsql Entity Framework Core Provider
- Swagger / OpenAPI
- JWT Authentication

### Frontend

- Angular 22
- TypeScript
- HTML / CSS
- Angular HttpClient
- Angular Signals

### Development Tools

- Visual Studio — Backend
- Visual Studio Code — Frontend
- PostgreSQL / pgAdmin
- Git / GitHub
